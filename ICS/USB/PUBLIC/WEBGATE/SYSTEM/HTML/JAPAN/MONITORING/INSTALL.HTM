Web Gate Installation

Follow the instructions below to download and install the Vijeo Web Gate ActiveX Control.
  1. Download the control by clicking the following link:

    Web Gate Installer

  2. Click Run when you see the dialog, "Do you want to run or save this file?"

  3. Click Run if you see the dialog, "The publisher could not be verified. Are you sure you wnat to run this software?"

  4. Click Finish when you see the message, "InstallShield Wizard Complete".
