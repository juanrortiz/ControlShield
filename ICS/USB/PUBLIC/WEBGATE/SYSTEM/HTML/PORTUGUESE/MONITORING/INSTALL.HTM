Instalação do Web Gate

Siga as instruções abaixo para instalar o Vijeo Web Gate ActiveX Control.
    Instale os arquivos necessários do DVD de instalação. <Unidade de DVD:>\Tools\Web Gate Client Files\Web_Gate_Client_Files.exe

    Ou

  1. Baixe o controle clicando no seguinte link:

    Instalador do Web Gate

  2. Clique em Executar quando vir a mensagem "Deseja executar ou salvar este arquivo?"

  3. Clique em Executar se vir a mensagem "Não foi possível verificar o editor. Tem certeza de que deseja executar este software?"

  4. Clique em Fim quando vir a mensagem "Assistente do InstallShield Concluído".

Para Windows Vista e Windows 7, é preciso configurar as políticas locais de segurança para permitir a instalação do Web Gate ActiveX control. Para configurar as políticas locais:
  1. No prompt de comando, execute secpol.msc.

  2. No diálogo Configurações de Segurança Local, expanda a pasta Políticas Locais.

  3. Selecione Opções de Segurança.

  4. Desabilite Controle da Conta do Usuário: Execute todos os administradores no Modo Aprovação Admin.

  5. Reinicie seu PC.
